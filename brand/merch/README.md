# VolksVision merch files: snowflake wheel

Send these straight to the printer or embroiderer. Everything is on a transparent background.

| File | Use it for |
|---|---|
| `chest-snowflake-wheel-white-4in-300dpi.png` | Left-chest print on **dark** shirts and hoodies (print about 3.5 to 4 in wide) |
| `chest-snowflake-wheel-black-4in-300dpi.png` | Left-chest print on **light** shirts |
| `back-print-white-15x18in-300dpi.png` | Full back print on **dark** garments (DTG / DTF size, 4500 x 5400 px) |
| `back-print-black-15x18in-300dpi.png` | Full back print on **light** garments |
| `snowflake-wheel-*.svg` | Vector master files. Screen printers and embroiderers prefer these. |
| `snowflake-wheel-white-1color.svg` / `black-1color.svg` | One-color versions (cheapest for screen printing, best for embroidery and patches) |

## Notes for the shop
- Colors: off-black `#0B0D0C`, white `#FFFFFF`, amber `#F2A93B` (on light garments the tagline uses a deeper amber `#B9721A` so it stays readable).
- Embroidery (caps, patches): use a one-color SVG, at least **2.25 in** wide so the spokes and lug holes hold their shape. Ask the digitizer to keep the four lug holes.
- No Volkswagen badge anywhere, on purpose: the wheel is an original drawing in the style of the classic snowflake wheel, so it doesn't use VW's trademark.
